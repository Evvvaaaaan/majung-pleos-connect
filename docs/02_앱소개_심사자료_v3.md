# 02 앱 프로젝트 소개 / 심사 자료 — 마중 (MAJUNG) v3 (접수양식 02 섹션에 붙여 넣을 텍스트)

> 대표자·구성원 성명, 연락처, 소속은 기재하지 않습니다.

**앱명 / 프로젝트명:** 마중 (MAJUNG) — 폰은 모르고 차만 아는 3가지로 끝내는 Pleos Connect 안심 픽업

## 1. 앱 한 줄 소개
마중은 혼잡한 학원가·역 앞 픽업의 마지막 100m에서, 스마트폰 위치 공유가 알 수 없는 세 가지 — **차가 정말 P단에 멈췄는지, 아이가 어느 문을 열었는지, 안전벨트를 맸는지** — 를 차량 신호로 확인해 동승자에게 "지금 타도 돼요"를 알리고 승차와 동시에 공유를 끝내는 차량용 앱입니다.

## 2. 기획 배경
내비게이션이 "목적지에 도착했습니다"를 말한 뒤부터 아이가 차 문을 열기까지가 학부모에게 가장 혼란스러운 구간입니다.
- **같은 색 SUV 행렬 속 내 차 찾기**: 앞차 때문에 약속 간판보다 두세 대 앞에 서면 아이는 차도 쪽으로 내려오거나 반대로 걷습니다.
- **주행 중 반복 통화**: 정차할 곳을 찾으면서 "어디야?" 전화를 받는 것은 Pleos 주행 안전 가이드가 경계하는 시각·인지 분산입니다.
- **택시 앱이 못 푸는 부분**: 위치 공유·도착 예정 시간·번호판 표시는 이미 있습니다. 없는 것은 차량 상태입니다. 폰은 차가 멈췄는지, 어느 문이 열렸는지, 벨트를 맸는지 모릅니다. 마중은 바로 이 공백을 Vehicle SDK 신호로 메웁니다.

## 3. 앱 주요 기능 및 차량 특화 요소
### 가. 차만 아는 3가지 (핵심, 전부 구현·테스트 완료)
1. **P단 정차 확인 → "지금 타도 돼요"**: `Gear.registerGearSelection`이 PARK를 주고 차속(AAOS `PERF_VEHICLE_SPEED`)이 0일 때만 동승자 웹 상태 카드가 바뀝니다. 차속 0이라도 D단이면 바뀌지 않습니다(테스트로 보장).
2. **차도 쪽 문 열림 즉시 경고**: `Door.registerDoorPosition(ROW_2_LEFT)` 열림 → 운전 부하 게이트를 우회하는 CRITICAL 음성 "차도 방향 왼쪽 문이 열렸습니다. 인도 쪽 오른쪽 문을 이용해 주세요."
3. **문 닫힘 + 벨트 체결 → 공유 자동 파기**: `Seat.registerSeatBeltBuckledState`와 도어 닫힘이 모이면 창문·독서등을 원복하고 일회성 링크를 서버에서 즉시 삭제합니다(DELETE). 센서 없는 트림은 능력 조회(`checkSeatBeltBuckledCapabilities` 등) 결과에 따라 수동 종료 버튼으로 전환됩니다.

### 나. 6단계 흐름 (트리거는 모두 차량 신호, 수동 버튼은 하나)
| 단계 | 트리거 | 동작 |
| :-- | :-- | :-- |
| 1 합의 | 운전자 시작 / Gleo 음성 | 기준 간판·차종·번호판 끝 4자리·일회성 웹 링크, NaviHelper 경로 |
| 2 접근 | 반경 80m + ≤25km/h + 우측 방향지시등 (50m 저속 폴백) | 동승자 웹 "들어오고 있어요" + 10m 단위 거리 |
| 3 식별 | VIN(`CarInfo.getVINInfo`) | 차종·번호판 상시 노출 |
| 4 정차 | 기어 P + 차속 0 + 60m 이내 | FusedLocation 신뢰도 ≥0.70일 때만 "간판 앞 12m" 자동 안내, 아니면 운전자 원탭 [간판 앞/정면/뒤] |
| 5 맞이 | **운전자 [주변 확인 완료] (유일한 수동, P단 아니면 거부)** → 문 열림 → 착좌 | 잠금 해제, 창문 25%(와이퍼 작동 시 0%), 독서등, Pleos TTS "○○님, 반갑습니다" |
| 6 종료 | 문 닫힘 + 벨트 체결 | 링크 즉시 파기, 20분 TTL 백업, 액추에이터 원복 |

### 다. 주행 안전 설계
- 운전 부하 지수(조향 각속도·브레이크·와이퍼·속도) ≥ 0.45 → 일반 안내 보류, 1.5초 안정 후 재생
- 5단계 중 D/R 전환 시 문 열림·벨트 미체결 → 출발 위험 경고
- 원격 도어 개방 없음(잠금 해제만), 동승자 폰 GPS 미수집, 차량 원시 좌표는 중계 서버가 폐기하고 10m 버킷 거리만 전달
- UX 제한(주행 중) 시 입력란 숨김, 터치 타깃 ≥ 56dp

## 4. 주요 사용 시나리오
**맞벌이 학부모의 저녁 학원가 픽업.** 출발 전 차량 화면에서 "파리바게뜨 대치점"을 고르면 아이 폰으로 링크가 갑니다. 아이는 설치 없이 웹에서 차종·번호판 끝 4자리와 "약 70m 남음"을 봅니다. 앞차 때문에 간판보다 12m 앞에 P단으로 서는 순간 아이 화면이 "차가 멈췄어요 · 간판 앞 12m"로 바뀝니다. 부모가 사이드미러로 후방을 보고 [주변 확인 완료]를 누르면 "지금 타도 돼요"가 뜨고 조수석이 풀립니다. 아이가 실수로 뒷좌석 차도 쪽 문을 당기면 즉시 "차도 방향 왼쪽 문이 열렸습니다"가 울립니다. 착좌하면 "지수님, 반갑습니다", 벨트를 매면 링크가 사라집니다.

**우천 역세권 마중.** 와이퍼 작동이 감지되면 창문 개방을 생략하고 잠금만 해제합니다. 지하주차장처럼 위치 신뢰도가 낮으면 거리 문구를 숨기고 운전자가 [간판 앞/정면/뒤]를 한 번 눌러 전달합니다.

## 5. 개발 계획 (현재 구현 상태)
- **구현 완료**: Android Kotlin(Compose) 차량 앱 pleos/sim 두 플레이버, Node.js SSE 중계 서버, 동승자 웹, 유닛 테스트 12건, 중계 서버 E2E, 릴리스 APK 2종.
- **SDK**: Vehicle 2.3.2(gear·brake·steering·wiper·turnSignal·door·seat·belt `register*`, door lock·window·reading light 쓰기, 능력 조회), NaviHelper 3.0.5(경유지 경로·취소), FusedLocation 1.1.3(연속 콜백·신뢰도), TextToSpeech 3.3.1(ON_DEVICE), AAOS CarPropertyManager(차속), CarUxRestrictionsManager(주행 제한).
- **2차 PT 전**: Pleos Connect 에뮬레이터 Virtual Console 신호 주입으로 트림별 능력 조회 응답·폴백 실증, 시연 영상 교체.

## 6. 기대효과 및 발전 가능성
- 운전자: 정차 구간 통화·메신저 확인 0회를 목표. 동승자: 번호판 대조 + 차량이 확인한 "멈춤" 신호로 오승차·차도 진입 위험 감소.
- 접점 확장: 운전자 1명당 비운전 가족 1.5~2명이 웹으로 현대차 SDV 경험을 접함([검증 전 가정]).
- 로드맵: 1) 무상 기본 픽업 → 2) 다자녀 학원 일정·키즈폰 SMS 구독형 → 3) 현대 카페이 제휴 주차장 회차 구역 안내.
